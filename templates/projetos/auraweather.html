O Contexto

Simplicidade contra a poluição.

A maioria dos apps de clima esconde a temperatura atual atrás de anúncios ou mapas pesados e interativos que não carregam rápido.

O AuraWeather foca apenas no essencial. Se você quer saber a condição de uma cidade, você digita o nome e os dados meteorológicos reais do OpenWeatherMap aparecem instantaneamente na tela.

Arquitetura

Stack Técnico

  • OpenWeatherMap API
    Conexão direta com a maior API meteorológica do mercado.
  • Geocoding Reverso
    Transformação da entrada em string do usuário para coordenadas lat/lon nativamente.
  • Tratamento de Erros Client-side
    Mapeamento de 404s (Cidade não encontrada) tratado visualmente sem refresh na página.
  • Design Minimalista Dinâmico
    Renderização dinâmica de UI baseada no código de clima reportado pela API.
